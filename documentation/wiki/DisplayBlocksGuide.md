### ***2.3.0***
_Note: Display blocks are not currently obtainable via recipes._
> Custom display blocks can be added via config.

**Plates:**

* While holding a Minecraft bowl, use `Shift + RMB` to place.
    * Use `RMB` on an empty plate to retrieve the bowl.
* While empty-handed, use `Shift + RMB` on empty plates to toggle plate size.
* Add servings by using `RMB` with a compatible food item or `Shift + RMB` to add all.
* Remove servings with `RMB` to remove one item or `Shift + RMB` to remove all.
* Some items can be served on both plate sizes.
    * Currently only applies to baked potatoes.
* When broken with `LMB`:
    * Full plate drops the block version. If partially filled, you receive the individual food items and a bowl.

**Bottles & Bowls:**

* Use `Shift + RMB` to place.
    * Use `RMB` to retrieve the item.
* Break the block with `LMB` to get the block version.

**Display Delight Compatibility:**
* Display Delight plates can be placed as Create: Food plates using `Shift + RMB`.
* Food items from Create: Food can be placed on Display Delight plates.
* Display Delight supported items can now be placed onto Create: Food plates.
* Bulk placement does not work for Create: Food supported items placed on Display Delight plates. Only single placement will occur.
* Includes recipes to convert plates/bowls.
